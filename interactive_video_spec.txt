# IMPLEMENTATION PROMPT: INTERACTIVE VIDEO-BASED ENGLISH LEARNING

Implement a complete **Interactive Video Learning System** for the English-learning platform.

The feature must allow teachers to create English lessons centered around videos. Students should watch the video through a modern **YouTube-style video player** while completing interactive English questions and activities that appear at specific points in the video.

The system must be fully integrated with the existing platform, including the existing user roles, courses, lessons, student progress, teacher dashboard, scoring, and AI assistant.

---

## 1. MAIN OBJECTIVE

Build an interactive English-learning experience:

**Watch Video → Interact → Answer Questions → Practice English → Receive Feedback → Continue Video → Complete Lesson → Track Progress**

This is NOT just a normal video player.

Teachers must be able to place English-learning activities at specific timestamps in the video.

Example:

```text
00:00 ───────── 02:15 ───────── 04:30 ───────── 07:20 ───────── 10:00
  │                │                │                │
  │                │                │                │
Video starts   Listening Q      Vocabulary       Grammar Q
                  ↓                ↓                ↓
              Student          Student          Student
              answers          practices        answers
```

When the video reaches a configured activity timestamp, the system can pause the video and display the activity.

# 5. ENGLISH ACTIVITY TYPES

Do NOT include:

* Code/Programming Activity
* File Upload Activity
* Discussion/Reflection Activity

The system should support these English-learning activities:

## A. Multiple Choice

Example:

"What does Sarah do every morning?"

A. She runs.
B. She reads.
C. She cooks.
D. She sleeps.

Teacher selects the correct answer.

---

## B. Multiple Select

Allow students to select more than one correct answer.

Example:

"Which activities does John do every morning?"

☐ Exercise
☐ Read
☐ Cook
☐ Walk

---

## C. True / False

Example:

"Sarah goes to school at 7:00."

True / False

---

## D. Fill in the Blank

Example:

"I usually ______ breakfast at 7:00."

Expected answer:

"eat"

Support acceptable alternative answers where appropriate.

---

## E. Short Answer

Example:

"What time does John wake up?"

Student enters an answer.

Allow teacher-defined expected answers and flexible matching where appropriate.

---

## F. Matching

Example:

Match the words with their meanings:

```text
Breakfast       → Morning meal
Teacher         → Person who teaches
Library         → Place for books
```

---

## G. Ordering / Sequencing

Example:

"Put Sarah's morning activities in the correct order."

1. Eat breakfast
2. Wake up
3. Go to school
4. Brush her teeth

Student rearranges the items.

---

## H. Drag and Drop

Use drag-and-drop interactions for:

* Vocabulary
* Sentence construction
* Matching
* Categorization
* Grammar exercises

Example:

Build the sentence:

```text
[goes] [school] [She] [to] [every day]

→ She goes to school every day.
```

---

## I. Image-Based Question

Teacher can provide an image and ask:

"What is the person doing?"

Students choose or write the answer.

Use this for:

* Vocabulary
* Speaking preparation
* Description
* Grammar practice

---

## J. Speaking Activity

Students should be able to practice speaking.

Examples:

### Repeat

"Repeat this sentence:

I usually wake up at seven o'clock."

### Read Aloud

Display a sentence and allow the student to record themselves reading it.

### Speaking Prompt

"What do you usually do in the morning?"

Student records an answer.

Where supported, integrate speech recognition/pronunciation analysis.

Show useful feedback such as:

* Pronunciation
* Accuracy
* Words detected
* Suggested corrections

Do not present automated pronunciation scoring as perfectly accurate. Allow teacher review where necessary.

---

## K. Listening Activity

The video itself should be usable as a listening resource.

Examples:

* Listen and choose the answer
* Listen and fill in missing words
* Listen and identify information
* Dictation
* Identify a word or phrase
* Identify who said something
* Identify the main idea

---

## L. Vocabulary Activity

Allow activities such as:

* Word → definition
* Word → image
* Word → translation
* Fill in the blank
* Choose the correct word
* Matching
* Categorization
* Synonyms
* Antonyms

Store vocabulary associated with the lesson.

---

## M. Grammar Activity

Support:

* Multiple choice
* Fill in the blank
* Sentence correction
* Sentence transformation
* Sentence ordering
* Drag-and-drop sentence building
* Choose the correct grammatical form

Example:

"She ______ to school every day."

A. go
B. goes
C. going

Correct answer: B

---

## N. Reading Activity

The transcript can also become a reading resource.

Support:

* Reading comprehension
* True/False
* Multiple choice
* Short answer
* Vocabulary identification
* Find information
* Matching

---

## O. Writing Activity

Students can complete writing tasks such as:

* Complete a sentence
* Write a short answer
* Write several sentences
* Write a paragraph
* Write an email/message
* Describe an image

For writing activities, allow:

* Teacher feedback
* AI-assisted feedback where enabled
* Grammar suggestions
* Vocabulary suggestions
* Writing score/rubric where configured

# 7. OPTIONAL VS REQUIRED ACTIVITIES

Teacher must be able to choose:

### Required

Student must complete the activity before continuing.

### Optional

Student may skip the activity.

Teacher should be able to configure whether students can:

* Retry
* Skip
* Continue after incorrect answer
* See correct answer immediately
* See explanation immediately

---

# 8. VIDEO NAVIGATION AND ANTI-SKIP OPTIONS

Teacher should be able to configure:

### Free Navigation

Students can freely seek through the video.

### Guided Learning

Students cannot skip required interactive sections without completing them.

### Required Completion

Students must:

* Watch required portions
* Complete required activities
* Reach the lesson completion requirements

Do not make the system unnecessarily restrictive.

# 10. RESOURCES / DOWNLOADS

Add a **Resources / Downloads** section to every video lesson.

The **teacher controls access** to these resources.

Teachers can:

* Add learning resources
* Add links
* Add documents/materials supported by the platform
* Set whether students can view or download each resource
* Remove resources
* Reorder resources
* Set resource descriptions

Students should only see resources that the teacher has made available to them.

Example:

```text
📚 Lesson Resources

Vocabulary List
[View]

Grammar Notes
[View / Download]

Practice Worksheet
[Download]

Additional Video
[Open]
```

The system must enforce teacher-controlled access at the backend, not only hide resources in the frontend.

The finished feature should feel like a modern **English-learning platform**, not a generic video-upload page.

The core experience should be:

**WATCH → LISTEN → UNDERSTAND → INTERACT → SPEAK → READ → WRITE → RECEIVE FEEDBACK → PROGRESS**

Prioritize:

* Simple navigation
* Modern UI
* Fast loading
* Clear feedback
* Strong accessibility
* Mobile responsiveness
* Reliable progress tracking
* Teacher control
* Student engagement

After implementation, test the complete teacher-to-student workflow end-to-end and fix all discovered issues before marking the feature complete.
